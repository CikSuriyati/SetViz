    Symbols to remember

    ∪union — in A or B (or both)
    ∩intersection — only what's in both
    A′complement — everything not in A
    −difference — in A but not B
    Δsymmetric difference — in one, not both
    ⊂subset — every element of A is in B
    ∅empty set — no elements at all
    n(A)the number of elements in A
